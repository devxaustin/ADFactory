# Monkey Island tileset layout

The single source of truth for what to draw and where it goes. Open `tileset_guide.png` next to this file: it shows every tile's position and index.

**Current sheet:** 16 columns x 39 rows = **256 x 624 px**, 80 blocks, 466 cells.
Priorities: **P1** = needed to reskin the current game (135 cells), **P2** = polish and variety (93 cells), **P3** = new areas, draw later (145 cells).

## Rules for the sheet

1. **Grid:** 16x16 px tiles, no margin or spacing. Tile index = `row * 16 + column` (the guide numbers every cell).
2. **Append-only.** Existing indices never move, so the game never breaks when you add art. New tiles are added in new rows at the bottom.
3. **Transparent PNG, no anti-aliasing.** Every pixel is fully opaque or fully transparent. Ground tiles are fully opaque.
4. **Animation frames are consecutive cells, left to right** (e.g. water = indices 32-35). The game cycles them in code.
5. **Edge sets** (green blocks): draw the patch terrain on the INSIDE of each border and leave the OUTSIDE transparent, so one set works over any ground. Layout of each 5x3 block:

```
 TL     top     TR     | in-TL   in-TR
 left   fill    right  | in-BL   in-BR
 BL     bottom  BR     | spare   spare
```
   `fill` is optional (a copy of the patch ground, for reference). The four `in-` tiles are the concave corners you need for L-shaped patches.
6. **Layers** (what each `Layer` column means in Tiled):
   - `ground` bottom layer, always fully painted. `detail` flat decoration over the ground. `objects` solid scenery. `above` drawn OVER the player (tree canopies, roofs), which is what lets the player walk behind things.
   - `gate:<flag>` a layer that is solid and visible until that story flag is set, then disappears (for example `gate:tiger_fed` for the Tiger's thicket).
   - Multi-tile stamps list a layer per row (`r0:above, r1:above ... r3:objects`).
7. **Solid** is the default collision for each tile. `walkable` tiles (bridges, stepping stones) override the solid water underneath.
8. **Palette:** use one bright, saturated 32-colour palette for everything. Lospec (lospec.com/palette-list) has many; Endesga 32 and Resurrect 64 are popular, colourful starting points.

## Suggested drawing order

1. **Start with the non-edge P1 tiles (about 75 cells):** the A variant of each ground, water, lava, the P1 decor and props, the trees, hut, boulder. Hard-edged terrain already looks far better than the placeholders.
2. **Then the five P1 edge sets (60 cells):** shore, sand_patch, path, lava_rim, pier_edge. These soften every border.
3. **Then P2** (variants B-D, extra trees, more decor, the big hut), then **P3** when we add the new areas.

## Using this with Tiled

- Create a tileset from `tileset.png` with tile size 16x16, 16 columns, no margin or spacing. Keep the filename the same when you replace the art so Tiled and the game keep their links.
- `tileset_manifest.json` lists every block with its index, layer, solid default, animation frames, and priority. The game loader (next step) reads it to set collision and animations automatically, and I will generate a ready-made Tiled tileset file from it so you never set properties by hand.
- Tell me any tile you want added, moved to a different priority, or removed and I will regenerate everything from the script in `tools/make_tileset_layout.py`. Indices only ever append.
